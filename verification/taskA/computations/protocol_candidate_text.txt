Executive scientific decision
This document specifies what it would take to independently reconstruct the published classical
spin–cavity dynamics and assess their characteristic period doubling and time-soliton statistics. The
published paper makes the source model sufficiently explicit for an independent implementation;
unavailable original input files/code, unrecovered figure-point arrays and random streams still prevent
an identical archived-code replay. The outcome of Manvitha B.’s separate kinetic-oscillator audit is
not evidence for a many-body time liquid. Its original energy-ledger FAIL and subsequent diagnosis
remain separate provenance objects.
Scope barrier: No HLV/Spiral-Time phase-memory feature or kinetic coefficient may be added in
DTL-ST-REPRO-001. A later diagnostic study and later kinetic-intervention study each require a
separate preregistered freeze. The square spin lattice is not the HLV 6D cut-and-project carrier; AΘ
is a coefficient, not a fifth operator.[K26]

Independent validation ladder – no outcome-driven changes
1. F0: Provenance/identity. Hash [W26] PDF; freeze extracted Eqs. (3)–(5), (12)–(16), essential
equations (6)–(11), and Supplement S11; record source commit, repository license, exact code
inputs, acquisition/permissions and all deviations. If source code or data remain restricted, mark
archived-code replay BLOCKED; allow independent reconstruction under that exact name.
2. F1:
Single-stage oscillator unit tests.
Verify ωc, τcav, temperature/noise variance and
stationary covariance from S2 by direct Monte Carlo; compare sampled impulse variance D∆t with
theoretical confidence intervals and inspect pre-equilibration effects. The source-only Langevin
dynamics must be verified before spins are switched on.
3. F2: Deterministic spin mechanics. Compare Strang integration against an independently
implemented adaptive solver on a predefined smooth deterministic drive. Check periodic boundaries,
neighbor sums, exact spin-norm conservation within a numerical error budget, O(∆t2) convergence
where an asymptotic regime is resolved, and source Supplement Fig. S10’s numerical behavior. No
random forcing in this gate.
4. F3: Stochastic convergence. On identical Brownian paths across resolutions (coarse increments
sum fine increments), assess weak-observable stabilization, uncertainties and comparison with a
separately implemented stochastic integrator. Do not expect pathwise equality for simulations
driven by independent noise sequences at different step sizes.
5. F4: Feasibility commitment. Before production: timed kernels, peak RAM, serialized outputs,
independent-trajectory chunking, exact resume/no-overwrite behavior, deterministic seed-to-trial
mapping and environment lock. The locked run cannot be replaced by a fast demonstrator. Any
departure from L = 100, Np = 104, Ntraj = 100 creates a different finite-size/sampling study.
6. F5: Original-physics reproduction. Run primary figure targets A and B with full declared
conditions; record all trajectories, aggregate uncertainty and numerical quality; perform secondary
targets as resources permit. The paper’s main qualitative phenomena must not be inferred from a
single selected favorable trajectory.
7. F6: Independent replication. A second implementation or lab compares source-native ob-
servables at matched physical/numerical conditions, with random-seed-independent statistical
comparisons. A reproduced figure-like pattern alone does not validate equilibrium physics or the
original experimental existence (no experiment exists in this study).

Threshold provenance. 10−10 in G01 is an engineering numerical tolerance, not a physical constant;
its adequacy must be verified against machine precision and run length. The published 0.418 and
10τosc are source-defined classification conventions, not our newly optimized thresholds. The 95%
uncertainty interval and Ntraj = 100 are sampling standards/source sample size, not proof that 100
runs are statistically sufficient for every rare-soliton tail. A result meeting selected gates while failing
any load-bearing physical reproduction is not an overall PASS.
Uncertainty. Independence unit is the full stochastic trajectory, never adjacent periods from the
same realization. Provide trajectory-level bootstrap with preregistered seed and ≥2000 resamples;
use simultaneous adjustment for explicitly multiple primary spectral or timescale comparisons, or
report them as exploratory until a familywise rule is frozen. For rare events with few or zero solitons,
give exact or interval-censored rate limits; no spurious precise estimates. Primary qualitative pattern
matching should additionally be supported by convergence and sensitivity.
Result labels. PASS: all frozen eligible load-bearing gates met. FAIL: a valid run decisively violates
any required claim/gate. INCONCLUSIVE: correct execution but insufficient power, unstable numerics,
or unresolvable source ambiguity. BLOCKED: missing legal source data, resources, critical parameters,
or code. INVALID: run breaks the frozen implementation/quality contract; no scientific verdict. A
pre-freeze technical feasibility exercise never counts as the frozen confirmatory run.

Compute cost, resource controls and original-code access
For L = 100, Ntraj = 100, Np = 104 and 20–40 substeps per period, the production demand is roughly
L2 × Ntraj × Np × Nstep/period ≈2 × 1011 to 4 × 1011 spin-site time-step updates per parameter point,
(8)
excluding cavity equilibration, parameter sweeps and multi-resolution comparisons. The product is
an operation-count proxy, not runtime. A full 2D phase map may be substantially more expensive.
Compute time may be outside a routine Colab session and is not claimed feasible without measured
kernel timing and resumable, validated chunking. A CPU-only Python loop over lattice sites would
be unsuitable; tested JIT/vectorized or GPU exact-rotation kernels may be needed.
The original Zenodo 23168407 is restricted; a request for permission is appropriate. Preserve original
SHA-256 and terms of access if granted. Never regenerate “original” HEK-like data or treat new
pseudorandom paths as historical author paths. Restricted original data do not block independent
reconstruction of the published equations; they do block strict data/code identity claims.
